## Formulación del modelo y metodología computacional

¿Cuál es la diferencia entre fenómeno físico, modelo matemático y método de simulación?

## Formulación del modelo

Se deben especificar:

- El objetivo del modelo.
- Los límites del sistema y las escalas representadas.
- Las entidades, variables de estado y observables.
- Las ecuaciones, reglas de evolución, probabilidades de transición, etc.
- Los parámetros, unidades, valores o intervalos junto con la fuente consultada.
- Las condiciones iniciales y de frontera, cuando correspondan.
- Los supuestos y simplificaciones adoptados.
- Las salidas que producirá el modelo y su interpretación científica.

## Metodología computacional

Se debe proponer:

- El método de simulación.
- La relación entre el modelo matemático y el método de simulación.
- El lenguaje, las librerías y la organización general del código.
- Los datos necesarios para establecer parámetros, calibrar o comparar el modelo.
- Los experimentos computacionales que se realizarán.
- Las estrategias previstas de verificación, validación y análisis.
- Los criterios mediante los cuales se interpretarán los resultados.

## Entregable esperado

- Documento estructurado con la formulación matemática, la metodología computacional, tabla con las variables y los parámetros del sistema, las ecuaciones o reglas definidas, diagrama de flujo o pseudocódigo del algoritmo principal, y estrategia preliminar para la verificación y validación del modelo.
