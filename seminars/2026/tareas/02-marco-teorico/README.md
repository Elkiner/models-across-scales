# Marco teórico e hipótesis

## Propósito

Redactar las bases conceptuales para la formulación del modelo.

## Entregable esperado

- Documento con el marco teórico redactado como un texto continuo, organizado y explicativo.

## Criterios de retroalimentación

- Coherencia entre el problema o fenómeno y la teoría presentada
- Rigor científico, técnico, matemático o computacional
- Claridad de los supuestos e hipótesis
- Justificación de la elección del modelo o motivación para la proposición del modelo
- Calidad y trazabilidad de las fuentes
